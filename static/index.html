KKuTu Static / Local

원본 KKuTu의 화면 구조, CSS, 이미지, 캐릭터 리소스와 효과음을 그대로 사용하면서 서버 통신만 브라우저 로컬 처리로 바꾼 버전입니다.

끝말잇기: 제시 글자로 시작하는 단어를 입력합니다. 쿵쿵따: 3글자 단어만 사용할 수 있습니다. 앞말잇기: 제시 글자로 끝나는 단어를 입력합니다.

로그인, 공용 DB, WebSocket 멀티플레이는 없으며 기록과 설정은 현재 브라우저의 localStorage에 저장됩니다.
